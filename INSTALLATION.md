# Installation / 安装

RightDisplay 0.3 Beta uses ad-hoc signing and is not Apple notarized. macOS may block the first launch because the developer cannot be verified.

RightDisplay 0.3 Beta 使用 ad-hoc 签名，尚未经过 Apple 公证。首次运行时，macOS 可能因无法验证开发者而阻止打开。

Installation / 安装步骤：

1. Download only from [official Releases](https://github.com/RedoRosetta/RightDisplay/releases).
   仅从官方 Releases 下载。
2. Compare SHA-256 with the matching release entry.
   核对同一发行页的 SHA-256。
3. Quit the old copy, extract and move `Right Display.app` to Applications.
   退出旧版，解压并放入“应用程序”。
4. Try opening normally. If blocked, go to **System Settings → Privacy & Security → Open Anyway**, then confirm. Finder's manual **Open** may also be used where macOS offers it.
   先正常打开；若被阻止，前往**系统设置 → 隐私与安全性 → 仍要打开**并确认。也可在 macOS 提供此操作时，在 Finder 中手动选择**打开**。
5. Grant only permissions needed by the features used.
   仅授予实际使用功能所需权限。

No need to disable Gatekeeper or SIP. If the downloaded checksum does not match, do not open the package. Keep a working previous app and record display settings before mode changes.

不需要关闭 Gatekeeper 或 SIP。下载文件校验值不一致时不要打开。模式切换前保留可用旧版及显示设置记录。

# RightDisplay 1.0.1 · Build46

## 中文

此更新改进 Virtual Audio 对 HDMI 多声道 PCM 的输出适配与软件音量控制链路：

- 移除过早的“非双声道”输出拒绝，将源端双声道Float32与目标设备当前PCM格式分别验证。
- 在现有HAL输出回调中适配Float32、signed Int16、packed Int24、24-in-32、Int32，以及大小端、交错/非交错格式；不主动改变设备或系统全局声道配置。
- 根据设备明确的preferred stereo channels或布局描述写入左右声道，其余声道静音；布局不明确、格式不一致或不支持的多stream布局明确拒绝，避免猜测映射。
- 转换器、映射及scratch在会话准备阶段固定；保留已有SRC/增益/静音、UID、身份验证、epoch/bounds、fail-silent与恢复策略。软件音量不改变显示设备硬件音量。

自动化PCM字节/边界/布局与48kHz/8ch/24-bit模拟链路已验证，含AddressSanitizer/UndefinedBehaviorSanitizer及原音频/恢复回归。**这不是新的真实HDMI播放、声学延迟、睡眠唤醒或长时硬件验收，不保证所有设备组合。**

App版本1.0.1、Build46；Apple silicon arm64、基础macOS14+，Virtual Audio另需macOS27+。共享协议21、组件21不变。

首方代码采用RNSL1.0非商业Source Available许可，不是OSI Open Source；Apple与第三方保留原许可和对应源码/替换权利。DMG配套本次提交源码及必要声明。

Ad-hoc签名，不是Developer ID签名，**未经过Apple公证**，不声称Gatekeeper认可。核对来源和SHA-256后先正常打开；如被阻止，使用系统设置→隐私与安全性中系统提供的“仍要打开”并确认。没有允许选项时不绕过策略，不全局关闭Gatekeeper/SIP。

## English

This update improves Virtual Audio's HDMI multichannel PCM output adaptation and software-volume path. Source stereo Float32 and target PCM eligibility are checked separately. The existing HAL callback converts to Float32, signed Int16, packed24/24-in-32 or Int32, in supported byte orders and interleaved/planar layouts, without changing global device formats.

Explicit stereo-channel metadata maps left/right; other channels are silent. Unknown layouts, inconsistent formats and unsupported multi-stream arrangements fail clearly. Conversion and scratch are prepared before the session, preserving existing gain, mute, SRC, identity, UID, epoch/bounds, fail-silent and recovery rules.

Byte/bounds/layout tests, simulated48kHz/8-channel/24-bit playback, sanitizers and existing regressions are automated evidence, **not new physical HDMI playback, latency, wake or long-duration hardware acceptance**. Not every device is verified.

# RightDisplay 1.0 · Build45

首次 1.0 正式发布，基于最终 UI-Aligned Build45。虚拟音频在会话开始前按实际规格准备 App 内 SRC 缓冲，运行时容量固定；修正大 I/O 消费窗口。共享 PCM ring 仍为32768帧，协议21/组件21，不宣称全链路动态扩容或所有历史中断已解决。

用户已确认当前机器上的持续播放、显示器唤醒恢复、手动停止后不恢复三项验收通过。重新构建及 Ad-hoc 重打包后已做定向自动化检查，未新增完整实机回归，不保证所有系统和硬件组合均已验证。

首方源码采用 RNSL 1.0 非商业 Source Available 许可；Apple 和第三方组件保留原许可证。不是 OSI 定义的 Open Source。

本独立分发包采用 **Ad-hoc 签名**，不是 Developer ID 签名，**未经过 Apple 公证**，不声称 Gatekeeper 认可。macOS 可能阻止首次打开：先正常打开，在系统设置 → 隐私与安全性中，核对来源后使用系统提供的“仍要打开”，按提示确认；不要全局关闭 Gatekeeper 或 SIP。若系统不给予允许选项，不绕过系统策略。

基础App：macOS14+、Apple silicon arm64；Virtual Audio另需macOS27+。软件音量改变转发音频，不改变电视硬件音量。系统回读不等于物理输出，EDID声明不等于当前输出，DSC仍是推断，ICC图表不是屏幕实测。

Ad-hoc发行使用精确组件内容绑定，防止同名组件替换；它不能证明下载发布者身份。仅从本仓库 Release 获取完整 DMG 并核对 SHA-256。已安装的其他发行组件可能需要使用其匹配卸载器安全移除后再安装当前组件；不关闭验证、不自动重启音频服务。

## English

First 1.0 release, based on the final UI-Aligned Build45. The App-side SRC buffer is planned before each session and stays fixed during forwarding; a large-I/O consumption-window issue is corrected. The shared protocol21/component21 PCM ring remains32768 frames. This does not resolve every historical dropout or introduce all-chain dynamic resizing.

Continuous playback, display-wake recovery and persistent manual-stop behavior passed the user's current-machine acceptance. The rebuilt Ad-hoc package received targeted automated checks, not a new complete hardware regression. Not every system/hardware combination is verified.

First-party code is RNSL 1.0 Noncommercial Source Available; Apple/third-party components retain their original terms. This is not OSI Open Source.

**Ad-hoc signed, not Developer ID signed; not Apple notarized.** No Gatekeeper approval is claimed. If macOS blocks opening, verify the origin and use its normal System Settings → Privacy & Security → Open Anyway flow where available. Never globally disable Gatekeeper/SIP or bypass a policy with no allow option.

Base app: macOS14+, Apple silicon; Virtual Audio: macOS27+. Software volume affects forwarded audio, not TV hardware volume. Component content pins do not authenticate the publisher. Download the intact DMG from the official Release and verify SHA-256. Prior component versions may require their matching safe uninstaller before the current package can be installed.

# RightDisplay 0.3 Beta

**Public Beta · Build 60 · macOS 14+ · Apple silicon arm64.**

## What's new

- **More trustworthy status:** current readings, inference and advertised capabilities presented separately; unknown stays unknown, DSC stays inferred.
- **Display Link Test:** check stable color-format, depth and HDR/SDR combinations on the current connection, with confirmation before potentially disruptive tests.
- **Consistent, safer controls:** shared Quick Control and advanced state; confirmation/readback and attempted recovery for supported mode changes. Configuration Protection locks manual display adjustments without locking brightness/volume.
- **Better inspection:** EDID interpretation and local diagnostic export with current evidence and selected recent events.
- **A more coherent Mac interface:** Light/Dark materials, compact menus/actions, device icons, a first-use guide and About window.
- **Brightness & Sound together:** supported brightness, writable audio outputs, compatible Apple TV output volume and optional keyboard control.

## 本次升级

- **更可信的状态：** 分开呈现当前读取、推断与声明能力；未知仍为未知，DSC 保持推断。
- **显示链路测试：** 检查当前连接的稳定颜色格式、色深及 HDR／SDR 组合，可能中断画面的测试需确认。
- **一致且更安全的控制：** 快捷控制与高级设置共享状态；支持的模式切换带确认、回读和恢复尝试。配置保护不锁定亮度／音量。
- **更完整的检查信息：** 完善 EDID 解读及本地诊断，整合证据与筛选后的近期事件。
- **更统一的 Mac 界面：** 浅色／深色材质、紧凑菜单／按钮、设备图标、使用引导与关于窗口。
- **亮度与声音整合：** 支持的亮度、可写音频输出、兼容 Apple TV 输出音量与可选键盘控制。

## Before installing / 安装前

This Beta uses ad-hoc signing and is not Apple notarized. If macOS blocks the first launch, use System Settings → Privacy & Security → Open Anyway, or Finder's manual Open where available. No need to disable Gatekeeper or SIP. See [installation](https://github.com/RedoRosetta/RightDisplay/blob/v0.3-beta/INSTALLATION.md). Minimum macOS 14; architecture: Apple silicon arm64.

本 Beta 使用 ad-hoc 签名，尚未经过 Apple 公证。首次运行被阻止时，前往系统设置 → 隐私与安全性 → 仍要打开，或在系统提供此操作时从 Finder 手动选择打开。不需要关闭 Gatekeeper 或 SIP。最低 macOS 14，架构为 Apple 芯片 arm64。

Switching/testing may blank the screen; recovery is attempted, not guaranteed. Color combinations depend on system/hardware negotiation. Apple TV/HomePod output control depends on pairing, network and writable volume availability. Test success is not universal certification. Review diagnostic/EDID attachments before sharing.

切换／测试可能黑屏，恢复为尝试而非保证。颜色组合受协商限制；Apple TV／HomePod 输出控制取决于配对、网络和音量可写性。测试通过不等于通用认证，分享诊断／EDID 前检查隐私。

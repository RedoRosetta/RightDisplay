# RightDisplay 0.4 Beta RC

**Apple silicon arm64 · Release configuration · ad-hoc signed · Public RC / 公开测试候选**

[Download / 下载](https://github.com/RedoRosetta/RightDisplay/releases/tag/v0.4-beta-rc)

## 已知问题 / Known issue

已知问题：本 RC 使用 ad-hoc 签名，虚拟音频可能因签名校验导致转发无法启用。所用版本仍保留部分 App／broker／driver 之间的 Apple 签名要求，这些校验与 ad-hoc 组件不兼容；虚拟音频尚未通过本 RC 的实际转发验收。

Known issue: ad-hoc signing may prevent Virtual Audio forwarding from starting. This version retains some Apple-signature requirements between the App, broker and driver; those checks are incompatible with ad-hoc components. Real forwarding has not been accepted for this RC.

## 本次升级

- **虚拟音频软件音量：** 为 macOS 没有可写音量的 HDMI／DP 输出提供软件音量，支持保存真实输出目标、条件满足时自动启动与异常中断后的显式恢复。不会改变电视硬件音量，也不会自动选择 macOS 默认输出。
- **ICC 独立页面：** 查看当前描述文件、检查外部 ICC、检查及套用可用描述文件；展示白点、原色、矩阵、色调曲线、参考色域与 VCGT。图表是文件模型，非屏幕实测或 GPU 当前 LUT 验证。
- **六页界面与 Quick Control：** 概览、显示、音频、ICC、EDID、通用统一卡片、控件、状态提示及交互更新；快捷面板共享状态与音量控制设备。
- **显示与证据：** 分辨率、HiDPI、固定刷新率／VRR、颜色格式／色深／范围／HDR 保留完整组合语义；EDID 声明、macOS 解析、系统当前报告与推断分开呈现。
- **保护与诊断：** 保留配置保护、切换确认、回读、恢复尝试及显式启动的链路测试；诊断报告主动保存到本地。
- **Apple TV／HomePod：** 继续提供兼容 Apple TV 的输出音量及支持的键盘控制；HomePod 跟随 Apple TV 的当前／默认输出。

## What's changed

Virtual Audio adds software volume for HDMI/DP outputs, saved target selection, conditional auto-start and explicit recovery. A dedicated ICC page adds profile inspection, selection and file-based gamut/calibration plots. Six pages and Quick Control share refined cards, controls and state. Display controls retain complete color combinations and evidence sources; configuration protection, confirmation, readback, attempted recovery and local diagnostics remain. Compatible Apple TV output volume and HomePod-through-Apple-TV support continue.

## 证据与使用边界 / Evidence and limitations

SLS-reported current state supports control readback; it is not receiver-side physical truth. Independent authoritative receiver-side current-state evidence is generally unavailable. DSC remains inferred. EDID advertises capabilities. ICC gamut/VCGT plots describe profile data, not measured display output or a currently loaded GPU LUT. A green forwarding indicator is not proof of audible or uninterrupted playback. Switching/testing may blank the screen; recovery is attempted, not guaranteed.

系统报告不等于接收端物理输出，独立的物理当前状态证据通常不可用；DSC 保持推断，EDID 保持声明能力。恢复、连接稳定性和音量可用性受系统、设备及网络影响。100% 软件音量对应内部 0 dB 增益，不构成物理 bit-perfect 输出承诺。

100% software volume represents 0 dB gain internally; it does not establish physical bit-perfect output.

## Installation / 安装

Base requirements: macOS 14+, Apple silicon arm64. Virtual Audio needs a newer macOS; the current driver, broker and removal-check code requires macOS 27.0 or later. Feature availability depends on the system and hardware.

基础系统要求为 macOS 14+、Apple silicon arm64。虚拟音频需要较新的 macOS，当前组件要求 macOS 27.0 或更新版本；各项功能可用性取决于系统和硬件。

Use the normal first-open flow, then Privacy & Security → Open Anyway, or Finder Open where offered. Do not disable Gatekeeper/SIP. See [installation](../INSTALLATION.md).

正常打开被阻止时，使用隐私与安全性 → 仍要打开，或系统提供时使用 Finder 打开。虚拟音频组件需要单独安装；仅替换 App 不会更新已安装的 broker／driver；自身组件签名校验可能阻止 ad-hoc 转发。

Build/signature/offline checks do not establish those runtime results. This is a public prerelease for testing, not the final 0.4 Beta.
